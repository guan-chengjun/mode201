# 二级圆柱齿轮减速器 · 3D 原理仿真

基于 Three.js 的交互式运动学仿真，直观展示"电机 → 两级齿轮副 → 输出轴"的减速传动过程。

## 运行

```
双击 start.bat，或在本目录执行:  python -m http.server 8000
浏览器打开 http://localhost:8000
```

（ES Module 需通过 http 访问，直接双击 index.html 无法运行。Three.js 已下载到 vendor/，离线可用。）

## 传动参数

| 项目 | 参数 |
|---|---|
| 第一级 | z1=18 → z2=54，传动比 3 |
| 第二级 | z3=18 → z4=54，传动比 3 |
| 总传动比 | 1 : 9 |
| 模数 | 2（全部齿轮相同，保证正确啮合） |

## 交互

- 左键拖拽旋转视角，滚轮缩放，右键平移
- **暂停/继续**：定格观察齿轮咬合位置
- **转速滑块**：调节输入转速（10–150 rpm），从动齿轮按传动比自动跟随
- **重置**：转角与粒子归零
- **动力流**：切换粒子动画，标记动力传递路径

## 技术要点

- **纯运动学**：所有齿轮转角都由输入轴累计转角 θ1 按齿数比解析推导
  （`applyKinematics`），调速、暂停均不会破坏啮合同步。
- **参数化齿轮**：同一模数下按齿数生成梯形齿形（`createGear`），
  齿 0 统一朝向 +X，装配时按 `φ = π − π/z` 标定初相，保证齿面对齐不穿模。
- **外部模型**：内置 GLTFLoader，将 `motor.glb` / `housing.glb` 放入
  `models/` 即可自动替换对应的程序化部件。齿轮本体刻意不采用外部模型——
  通用 glb 齿轮的齿数/模数任意，无法满足严格传动比要求。
- 无物理引擎，仅 Three.js（本地 vendor，r160），零构建直接运行。
